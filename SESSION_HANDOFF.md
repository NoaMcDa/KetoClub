## 1. The rules this build ran under (keep them)

- One PR per GitHub issue into `main`. Workers build in isolated worktrees on
  branches `claude/<slug>-<issue#>`; CI is the judge; squash-merge on green
  with the full 40-char head SHA; unsubscribe after merge.
- **Never run tests locally** (no `flutter test`, `flutter drive`, `pytest`,
  `tool/check.sh`). Before any push: `flutter pub get`, `flutter gen-l10n`
  after ARB edits, `dart format lib test integration_test test_driver tool`,
  `flutter analyze --fatal-infos --fatal-warnings` clean; backend: `uv sync
  --frozen`, `ruff check`, `ruff format --check`, `mypy app tests`.
  `/opt/flutter/bin` must be on `PATH`.
- Merge `origin/main` into a PR branch (never rebase or force-push a
  worker's branch); resolve keep-both; watch initializer lists (`,` vs `;`);
  PRs that touch the same screen merge one at a time, each merging main first.
- Commit trailers: `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`
  and `Claude-Session: <this session's URL>`. PR bodies end with
  `🤖 Generated with [Claude Code](https://claude.com/claude-code)` + the
  session URL. GitHub comments end with
  `---\n_Generated by [Claude Code](https://claude.ai/code)_`. No model name
  anywhere in repo content.

## 4. Only a person can do these

`restaurant-api.wolt.com`, `consumer-api.wolt.com`, `www.10bis.co.il` and
`generativelanguage.googleapis.com` are denied by the sandbox's network
policy. From any laptop:

```bash
tool/record_wolt_fixture.sh vitrina-lilinblum   # #22; also settles research §2.5 (empty-body report)
curl -sS 'https://consumer-api.wolt.com/v1/pages/restaurants?lat=32.07&lon=34.77' \
  -H 'platform: Web' -H 'app-language: en' > wolt_pages_restaurants.raw.json      # #38
curl -sS 'https://restaurant-api.wolt.com/v1/pages/search' -H 'content-type: application/json' \
  -H 'platform: Web' -d '{"q":"vitrina","target":"venues","lat":32.07,"lon":34.77}' \
  > wolt_pages_search.raw.json                                                     # #38
```

Then redact and check in per `phase2_discovery_research.md` §2.4 (the
fixtures replace `test/fixtures/wolt_pages_*.json`; `_fixture_note` first
key; the shape tests say whether the mappers survive). #44 is the same for
10bis through the backend proxy (`backend/README.md`). The Gemini smoke test
is `backend/README.md` "Manual end-to-end check". #65's numbers come from a
phone on 4G into `docs/RELEASE.md` §5. `docs/RUNNING_IOS.md` has the first
real device run.
