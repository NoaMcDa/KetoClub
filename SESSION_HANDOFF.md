  `tool/check.sh`. CI is the judge. Required before any push: `flutter pub get`,
  `flutter gen-l10n` after ARB edits, `dart format lib test integration_test
  test_driver tool`, `flutter analyze --fatal-infos --fatal-warnings` clean
  (backend: `uv sync --frozen`, `ruff check`, `ruff format --check`, `mypy app
  tests`). `/opt/flutter/bin` must be on `PATH`.
- Subscribe to each PR (`subscribe_pr_activity`), read job logs on red, fix in
  the worker's worktree, push; squash-merge on green with the full 40-char
  head SHA; unsubscribe after merge. The user sometimes merges PRs themselves
  (merge commits) before CI finishes — verify `main` afterwards.
- Merge `origin/main` into a PR branch (never rebase or force-push a worker's
  branch); resolve conflicts keep-both; watch initializer lists (`,` vs `;`).
- Ask the user when in doubt; run independent work in parallel; do not stop
  until everything planned is merged.
- Commit trailers: `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`
  and `Claude-Session: https://claude.ai/code/session_019LqMSq3Wd6CQ9GqZccEtfy`
  (a new session uses its own session URL). PR bodies end with
  `🤖 Generated with [Claude Code](https://claude.com/claude-code)` + session
  URL. GitHub comments end with `---\n_Generated by [Claude Code](https://claude.ai/code)_`.
  No model name anywhere in repo content.
